# Smart Campus Information Hub

## Problem
Students struggle to access important college information
because it is scattered across different sources.

## Solution
A centralized campus information platform with smart search.

## Features
- Smart Search
- College Announcements
- Exam Schedules
- Academic Information
- Events & Competitions
- Fees & Scholarships
- Forms & Documents
- Contact Directory

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Google AI Studio
- ...
